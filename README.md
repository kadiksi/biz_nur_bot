# Corner Group · Оперативные данные

Сайт и Telegram-боты над общим слоем `app/services/`. В 1С ничего не пишется.

## Запуск

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env                  # вписать OWNER_TELEGRAM_ID
python -m scripts.seed_demo --reset   # демо: 3 компании × 6 месяцев
pytest

python -m app.run                 # главный бот + сайт (нужны BOT_TOKEN_MAIN, OWNER_TELEGRAM_ID, ANTHROPIC_API_KEY)
```

Постоянная работа (служба macOS: старт при входе в систему, перезапуск после сбоя, Mac не засыпает от простоя):

```bash
scripts/service.sh install     # установить и запустить
scripts/service.sh restart     # после обновления кода или .env
scripts/service.sh status | logs | uninstall
```

Пока служба установлена, не запускайте `python -m app.run` / `app.bots.main_bot` вручную — второй бот будет конфликтовать с первым.
Лог: `~/Library/Logs/corner-ops/run.log`.

Вход на сайт: команда `/site` в главном боте присылает одноразовую ссылку (10 минут),
вход запоминается на 30 дней. Сайт открывается только из той же сети, что и этот компьютер.
Отдельно: `python -m app.bots.main_bot` — только бот, `python -m app.web` — только сайт.

## Устройство

- `app/models.py` — схема БД, `app/catalog.py` — компании, отделы, показатели.
- `app/services/` — единственная точка чтения и записи. Первый аргумент — `Actor` (кто и откуда).
  - `access.py` — все правила доступа.
  - Записывающие функции помечены `@write_op` и поддерживают `dry_run`:
    `changes.preview(...)` показывает, что изменится, `changes.apply(...)` пишет и добавляет строку в `change_log`.
- Производные показатели (средний чек, CPL, ROMI, маржа) считаются формулой от агрегатов,
  поэтому холдинг считается корректно.
- Факт текущего месяца в демо-данных пропорционален прошедшим дням.

## Главный бот

- `app/agent/tools.py` — инструменты Claude: чтение выполняется сразу, запись только готовит предпросмотр.
- `app/agent/runner.py` — цикл tool use. История только дополняется; `/new` начинает новый разговор.
- `app/bots/pending.py` — кнопка «Подтвердить»: перед записью предпросмотр строится заново,
  и если данные успели измениться, бот показывает обновлённый вариант вместо записи.
- История разговора и неподтверждённые изменения хранятся в памяти: после перезапуска бота они теряются.

## Сайт

- Страницы собирает главный бот (`save_page`, `update_page`, `delete_page`, `restore_page` в `app/agent/tools.py`),
  с тем же подтверждением кнопкой. Логика и проверка блоков — `app/services/site.py`, прошлые версии — `site_page_versions`.
- Страница хранит только состав блоков (heading, text, kpis, table, chart, kanban, summary). Цифры читаются
  через `app/services` с правами зрителя при каждом открытии, поэтому изменения из бота видны сразу.
- `app/web/` — FastAPI + Jinja2 + HTMX, Chart.js и SortableJS лежат локально в `static/vendor`.
- Канбан на сайте: перетаскивание пишет через `kanban.move_card`, в `change_log` с каналом `site`.
- Вход — `app/services/webauth.py`: в базе только хеши токенов; GET по ссылке ничего не гасит,
  вход — по кнопке (POST), чтобы превью ссылок не «съедали» её.

## Голосовые и аудио

Главный бот расшифровывает голосовые, кружки, аудио и видео (до 20 МБ и 2 часов) прямо на этом компьютере: whisper.cpp,
модель large-v3-turbo. Записи никуда не отправляются и после расшифровки удаляются; в Claude уходит только текст.
Модель (≈ 550 МБ) скачивается при первом голосовом, заранее — `python -m app.integrations.speech`.
Личное голосовое — поручение боту; пересланное и аудиофайл — материал, команды внутри него бот не выполняет.
Язык определяется сам; зафиксировать — `SPEECH_LANGUAGE=ru` в `.env`.

## 1С

Только чтение через стандартный интерфейс OData: `app/integrations/onec.py` делает лишь GET-запросы, в 1С ничего не пишется.

1. В 1С опубликуйте базу на веб-сервере с галочкой «Публиковать стандартный интерфейс OData». В самой базе
   обработкой «Настройка состава стандартного интерфейса OData» включите нужные регистры, документы и справочники.
2. Заведите в 1С пользователя только с правами на чтение.
3. Скажите боту «подключи базу 1С …». Он пришлёт ссылку на форму сайта, где вы вводите адрес, логин и пароль.
   Сайт проверяет связь и сам дописывает строки в `.env`, уже существующие подключения не меняются.
   Можно и вручную, по три строки на базу (ИМЯ — любое латиницей):
   ```
   ONEC_UT_URL=http://1c-server/ut/odata/standard.odata
   ONEC_UT_USER=bot
   ONEC_UT_PASSWORD=...
   ```
   `.env` перечитывается при каждом обращении, перезапуск не нужен.
4. Напишите главному боту, например: «подключи выручку и заказы из 1С». Бот сам:
   - находит объекты в базе и смотрит их поля и данные;
   - считает пробное значение за месяц и показывает, откуда оно;
   - после «Подтвердить» сохраняет источник (`onec_sources`);
   - загружает историю.

Дальше факты за прошлый и текущий месяц подтягиваются сами каждые `ONEC_SYNC_MINUTES` минут (по умолчанию 60).
Пишутся только факты, планы не трогаются. Каждая загрузка, в которой что-то изменилось, попадает в `change_log`.
Метка свежести на сайте берётся из `sync_status` (source `1c`); ошибки видны там же и в `onec_list_sources`.

## Внешние сервисы и Google Таблицы

- Главный бот сам подключает любые HTTP API (`app/services/connectors.py`). Подключения хранятся в `service_connections`; бот ходит только по их адресам.
- Ключи хранятся только в `.env`:
  - бот вызывает `request_secret` и присылает ссылку на страницу сайта `/secret/…`;
  - владелец вводит ключ или загружает JSON-файл, сервер пишет его в `.env` (`app/services/secrets.py`);
  - бот видит только имя ключа и сразу продолжает задачу.
  - Служебные ключи (Telegram, Claude, база, сайт, `ONEC_*`) бот менять не может.
- Чтение (`service_request`, `sheets_read`) выполняется сразу. Изменения во внешних сервисах (`service_write`, `sheets_write`) — только с подтверждением и только если у подключения `allow_write=true`. Адреса 1С сюда не подключаются.
- Google Таблицы:
  - открытые по ссылке читаются без ключа;
  - закрытые и запись — через сервисный аккаунт (`auth=google`, JSON-ключ через `request_secret`).
- Чтобы разбираться в незнакомых API, бот пользуется поиском и чтением страниц Anthropic (`web_search`/`web_fetch`). Отключить: `CLAUDE_WEB_TOOLS=false`.
